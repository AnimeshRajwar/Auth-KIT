# 🔐 AuthKit

A self-hosted authentication service with a **built-in dashboard UI** — like a personal Supabase for auth.  
Built with **Fastify + Node.js**. Drop it alongside any project.

> "i was tired of writting same logic for sign up and log in , so i made myself a auth service which i can use in any of my projects"
